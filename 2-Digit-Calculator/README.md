# Simple Python Calculator

This is a terminal-based calculator built with Python.

It takes two numbers from the user and performs mathematical operations using a looping menu system.

## Features

- **Addition** (Adds two numbers)

- **Subtraction** (Subtracts the second number from the first)

- **Multiplication** (Multiplies two numbers)

- **Division** (Divides the first number by the second)

- **Exponentiation** (Raises the first number to the power of the second)

- **Roots** (Calculates the custom root of the first number)
